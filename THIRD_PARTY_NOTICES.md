# Third-party code

Schematica Plus includes vector utilities, GUI controls and inventory helpers from
LunatriusCore 1.2.1-GTNH, revision `48cf796e6be47d3f3eb57cf0bc0febbe7b53cc82`.
Upstream: https://github.com/GTNewHorizons/LunatriusCore

Copyright (c) 2014 Jadran "Lunatrius" Kotnik. Licensed under the MIT License; the full
license is included in `src/main/resources/META-INF/LICENSE-LunatriusCore.txt` and in
the distributed jar. The copied classes have been relocated to
`com.github.lunatrius.schematica.internal.lunatriuscore` to coexist with external
LunatriusCore installations. Its mod entry point and global GUI hooks are not bundled.

## Litematica and MaLiLib UI

The original UI asset imports include material from Litematica 26.1.2-0.27.8 and MaLiLib
26.1.2-0.28.8, by masa, Sakura-Ryoko and their contributors, under LGPL version 3.
Upstream projects: https://github.com/maruohon/litematica and
https://github.com/maruohon/malilib. The MaLiLib reference checkout is
https://github.com/sakura-ryoko/malilib/tree/d194eb689d60f13ba39df4ab525dca64b1cf4478.
The initial Litematica assets came from the source snapshot at the version above.
Current behavior and translation references are Litematica 26.1.2-0.27.12 and
MaLiLib 26.1.2-0.28.11; their pinned revisions are recorded in HANDOUT.md.

- `assets/schematica_plus/textures/gui/litematica_widgets.png` is the unmodified
  Litematica `assets/litematica/textures/gui/gui_widgets.png` atlas.
- `assets/schematica_plus/textures/gui/malilib_widgets.png` is the unmodified
  MaLiLib `assets/malilib/textures/gui/gui_widgets.png` atlas.
- `assets/schematica_plus_litematica/lang/*.lang` contains the complete upstream
  language catalogs (14 Litematica locales and 13 MaLiLib locales), combined into
  14 locale files and converted from JSON to the 1.7.10 language format. Original
  keys and translator credits are retained; `tools/import_translations.py` applies
  selected functional branding and legacy format-placeholder repairs.
- Java files carrying `SPDX-License-Identifier: LGPL-3.0-only` adapt upstream
  UI layouts, layer-range/color-editor behavior, area-manager rows, Normal/subregion editors, file-manager/text/confirmation dialogs, color options and defaults,
  icon coordinates and drawing conventions to the internal 1.7.10
  controls. Their headers identify the 2026 modifications by HackerRouter.

- The `.litematic` writer follows the version 4 format of the 1.12.2 Litematica
  (maruohon/litematica, branch `liteloader_1.12.2`, LGPL-3.0), and `DataVersions`
  lists the data version names of MaLiLib's `Schema`.
- `assets/schematica/data/legacy_block_states.txt` is a table of Minecraft 1.12
  block state names, numeric IDs and metadata values, generated by
  `tools/generate_legacy_block_states.py` from the block state flattening table of
  the Minecraft 1.13.2 server; it contains no Minecraft code.

These files retain LGPL-3.0 and are exceptions to the repository's MIT license.
The two upstream license texts and the incorporated GPL version 3 text are
distributed in `META-INF/LICENSE-Litematica-LGPL-3.0.txt`,
`META-INF/LICENSE-MaLiLib-LGPL-3.0.txt` and `META-INF/LICENSE-GPL-3.0.txt`.
The modified source and build scripts are supplied in this repository and its
source distribution: https://github.com/HackerRouter/Schematica-Plus.
No MaLiLib runtime is bundled; button backgrounds are resolved from the running
Minecraft 1.7.10 resource pack.

## Syncmatica and Schematic Synchronizer

The server schematic and shared placement screens follow the layouts of Syncmatica
26.3-0.3.20 (https://github.com/sakura-ryoko/syncmatica, originally
https://github.com/End-Tech/syncmatica) and Schematic Synchronizer for 26.2
(https://github.com/xiader-45/Schematic-Synchronizer), both dedicated to the public
domain under CC0 1.0 Universal.

- `assets/schematica_plus_sharing/lang/*.lang` contains their language catalogs with
  the original keys, converted from JSON by `tools/import_sharing_translations.py`;
  `tools/translations/schematic_synchronizer_zh_cn.json` adds a Simplified Chinese
  translation of the Schematic Synchronizer keys.
- `assets/schematica_plus/textures/gui/sync_server_icon.png`,
  `sync_server_icon_highlight.png`, `sync_download_icon.png` and `sync_upload.png` are
  the unmodified Schematic Synchronizer `server_icon`, `server_icon_highlight`,
  `download_icon` and `upload` textures.
